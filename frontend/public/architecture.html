1 产品全景

NovelForgeX 围绕 Novel 展开，覆盖从创建、世界观/人物/大纲自动生成、逐章 beat-by-beat 续写、章后审计管线到数据采集、拆书学习、提示词优化的完整闭环。

flowchart LR A[创建小说] --> B[Bootstrap] B --> B1[世界观生成] B --> B2[核心人物生成] B --> B3[宏观大纲生成] B3 --> C[大纲确认] C --> D[逐章写作] D --> D1[Beat 节拍规划] D1 --> D2[Beat-by-Beat 流式续写] D2 --> D3[章后管线] D3 --> D4[质量审核] D4 -->|通过| D5[保存章节] D4 -->|不通过| D2 D5 --> D[下一章] D5 --> E[数据看板] D5 --> F[发布中心] F --> G[番茄/起点]

Novel

作品根资源，包含标题、题材、标签、简介、目标章数、每章字数。

Bootstrap

创建后 SSE 流式生成世界观 → 人物 → 大纲，前端实时展示并确认。

Beat-by-Beat

章节按节拍 (beat) 逐段生成，每个 beat 流式输出到 Tiptap 编辑器。

章后管线

续写完成后自动执行一致性检查、质量雷达、风格漂移检测。

学习闭环

每日热门采集 → 每周拆书学习 → 每周提示词优化。

2 六大引擎

系统按职责划分为六大引擎，各引擎独立演进，通过 Novel 模型和 StageModelResolver 连接。

创作引擎

  • NovelBootstrapper — 新书初始化 (世界观/人物/大纲)
  • ChapterWriter — beat-by-beat 流式章节生成
  • ContextBuilder — 上下文窗口构建
  • OutlineGenerator — 宏观大纲与节拍规划
  • PostPipeline — 章后自动管线
  • AutopilotDaemon — 全托管自动写作
  • VectorStore — 向量检索增强

拆书引擎

  • BookImporter — 多格式导入 (TXT/EPUB)
  • ChapterSplitter — 智能章节切分
  • EntityScanner — 实体扫描提取
  • ChapterExtractor — 深度章节分析
  • Aggregator — 多章聚合报告
  • StyleFingerprint — 文风指纹提取

世界引擎

  • WorldItem — 世界条目 CRUD (地点/势力/物品/规则/历史)
  • Character — 角色管理 (主角/反派/配角/导师/恋人)
  • OutlineNode — 大纲树 (卷/幕/章/场景/节拍)
  • 伏笔追踪（沉淀在章后管线）

审核引擎

  • QualityRadar — 多维质量雷达图
  • ConsistencyChecker — 前后文一致性检查
  • StyleDriftDetector — 文风漂移检测

数据引擎

  • DataCollector — 番茄小说数据采集
  • FanqieStats — 阅读/收藏/评分实时统计
  • ReadPredictor — AI 阅读量预测

学习引擎

  • HotCrawler — 多平台热门小说采集
  • KnowledgeExtractor — 拆书知识提取
  • PromptOptimizer — 提示词自动优化

8 创作工作流

新书初始化 (Bootstrap)

sequenceDiagram participant U as 用户 participant FE as Dashboard participant SSE as SSE Stream participant BS as NovelBootstrapper participant LLM as LLM API participant DB as SQLite U->>FE: 创建小说 (标题/题材/章数/字数) FE->>DB: POST /novels → 保存 FE->>SSE: GET /creation/{id}/bootstrap SSE->>BS: 启动流式初始化 BS->>LLM: 生成世界观 BS->>DB: 保存 WorldItems BS-->>SSE: world done + data Note over BS: sleep 5s BS->>LLM: 生成核心人物 BS->>DB: 保存 Characters BS-->>SSE: characters done + data Note over BS: sleep 5s BS->>LLM: 生成宏观大纲 BS->>DB: 保存 OutlineNodes BS-->>SSE: outline done + data BS-->>SSE: complete SSE-->>FE: 展示结果面板 U->>FE: 确认 → 进入创作台

逐章续写 (Beat-by-Beat)

sequenceDiagram participant U as 用户 participant ST as StudioPage participant CW as ChapterWriter participant CB as ContextBuilder participant LLM as LLM API U->>ST: 点击续写第 N 章 ST->>CW: SSE /creation/{id}/stream?chapter=N CW->>CB: build(novel_id, chapter_number) CB-->>CW: 上下文 (前文摘要/角色/大纲/节拍) loop 每个 Beat CW-->>ST: beat_start (摘要) CW->>LLM: 生成 beat 内容 (流式) loop 流式 chunks LLM-->>CW: text chunk CW-->>ST: chapter_chunk → Tiptap 插入 end CW-->>ST: beat_done (字数) end CW->>CW: 保存章节到 DB CW-->>ST: chapter_saved

ContextBuilder

为章节生成构建上下文窗口：前 N 章摘要、角色状态、世界设定、当前章节大纲节拍。上下文输入 LLM 的 system prompt。

PostPipeline

章节完成后自动执行：摘要生成、字数统计、角色追踪更新、伏笔检查。由 post_chapter_pipeline 阶段 LLM 驱动。

PromptLoader

从 DB prompt_templates 表加载提示词模板，支持变量替换。模板不存在时使用硬编码 fallback。

AutopilotDaemon

全托管模式：自动规划节拍 → 逐章续写 → 章后管线 → 循环下一章。可暂停/恢复。
