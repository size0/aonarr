# 玄幻

## 基本信息
- id: xuanhuan
- name: 玄幻
- name_en: Xuanhuan Fantasy
- description: 以修炼体系、功法秘术、宗门势力为核心的东方幻想题材

## 章节类型
- 修炼突破章：主角或关键角色修为提升
- 战斗爆发章：对决、比武、围杀
- 探宝奇遇章：秘境、遗迹、机缘获取
- 势力博弈章：宗门、家族、王朝间的角力
- 日常过渡章：修炼日常、人际互动、信息铺垫

## 爽点类型
- 打脸：以弱胜强、装逼反杀
- 升级突破：修为飞跃、瓶颈突破
- 收益兑现：物资获取、宝物入手
- 势力碾压：以一己之力震慑一方
- 身份揭示：隐藏身份曝光引发震撼
- 伏笔回收：早期铺垫的意外收获

## 节奏规则
- 三章内必有明确爽点反馈
- 每 5 章至少一次小高潮（战斗/突破/打脸）
- 每 15-20 章一个阶段性大高潮
- 低谷不超过 2 章，第 3 章必须翻转
- 新角色出场后 3 章内必须产生冲突或利益关系

## 数值体系规则
- 金手指能力必须有明确限制和代价
- 资源获取遵循递减效用（同级资源价值随修为提升而降低）
- 修炼速度需要合理解释（天赋/机缘/功法/药物）
- 战力体系不可随意通胀，低阶对高阶必须有明确差距描写
- 物品/灵石数量需前后一致，不可凭空增减

## 语言铁律
- 力量感通过**物理感受**传达，不用抽象数字（错：攻击力提升30% → 对：拳风过处，三尺内的空气都在颤鸣）
- 修炼境界描写要有**体感**（错：他突破到了金丹期 → 对：丹田内一颗金色光球缓缓凝聚，浑身骨骼发出噼里啪啦的脆响）
- 战斗场面用**节奏感短句**，避免长段落描述（拳至！ 剑出！ 两道气劲在虚空炸裂——）
- 内心活动不用旁白，用**行为和微表情**暗示

## 题材禁忌
- 禁止主角无条件善良或圣母
- 禁止战力体系崩塌（低阶无理由胜高阶）
- 禁止长篇心理独白取代剧情推进
- 禁止"旁白式"解释设定（融入角色体验中展示）
- 禁止重复使用相同的战斗套路超过 2 次

## 叙事指导
- 情节驱动以**利益和生存**为核心动力
- 主角行为动机要符合**趋利避害**本能
- 配角要有各自利益诉求，不做工具人
- 反派要有合理动机，不做纯粹的恶
- 世界观展开通过**主角亲历**，不做百科全书式铺排
